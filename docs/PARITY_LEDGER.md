# Native macOS parity ledger

This ledger tracks the PC Complete Collection port against the original game resources, the recovered FreeSO behavior, and the user-approved parity plan. “Partial” means there is working code but the complete player-facing flow or its verification is missing. Static references, successful builds, and data extraction alone do not establish parity.

The original executable exports under `analysis/full-decompilation/` are behavior evidence alongside the IFF resources. `0055cb93.c` traces the neighborhood lifecycle, including the `-1` home return and neighborhood fade/background events. `005607f3.c` records a related neighborhood state route. `00424260.c` reads the original `money_for_new_family` and `new_family_start_hour` tuning values. These address-based exports still require comparison with original resources and runtime behavior before they establish a complete flow.

Zoning does not change which controllers a lot carries.
- **Cloud session on `runtime/game` (house 5), after the controller fix:** `--check-sleep` passed once it stopped borrowing Studio Town's Insanity controller, which no longer exists on home lots. `--check-career-requirements` passed once it handled overnight shifts: with zero friends, Science level 1 (23:00–05:00) is the only level whose promotion needs a skill. Old Town lots 56, 63, 69, 76 and 77 get no village controller. A lot whose OBJT lists none falls back to the house-number rule. After the change, `--check-school`, `--check-services`, `--check-social`, `--check-travel` (lots 21, 40, 58, 81 and 93, with save/load and return home), `--check-expansion-lifecycle` and `--check-visitors` on lots 51 and 56 passed. `--check-visitors` cannot open Downtown, Vacation or Magic Town lots directly, because their ped markers expect the cross-lot state of a family that travelled in (lot 21 fails in `Bring a guest not here already`, lot 41 in `Family Spawn`). This failed before the change too and is a limit of the check, which `--check-travel` covers. Mode 18 (Build the Downtown Sim) now takes the false branch instead of crashing when no sim is travelling.
- **Findings:** cancelling the work interaction does not trigger the original demotion path; each pack has roughly 30 interactions whose action routine is absent from its own file, and two have an unreadable interaction table (Superstar, Makin' Magic); newspaper delivery differs between game folders, so `--check-services` reports it.
